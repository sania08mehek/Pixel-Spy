SQL Injection (SQLi)

SQL injection occurs when an application passes unvalidated user input directly to a database query. PixelSpy monitors all fetch() and XHR requests in real-time and uses a heuristic engine to flag suspicious parameters.

Medium Risk Scenario 1: Numeric ID Lookup
Fetching a user by ID using /api/user?id=101. PixelSpy flags the "id" parameter name and numeric value as a potential injection target.
