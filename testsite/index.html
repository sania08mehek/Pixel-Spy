Welcome to PixelSpy Lab

This environment is designed to test and demonstrate the security analysis capabilities of the PixelSpy DevTools extension. Each module contains real-world vulnerability patterns that PixelSpy can detect in real-time.

🚀 Getting Started
To begin your security audit, follow these simple steps:
  1. Open DevTools (F12 or Right Click > Inspect).
  2. Select the PixelSpy tab.
  3. Navigate to one of the labs using the menu above.
  4. Click the "Trigger" buttons in the labs to see security events appear in PixelSpy.
